# otp-id-go

Official Go SDK for the [OTP.ID](https://otp.id) V3 API — multi-channel OTP
delivery and verification (WhatsApp, SMS, Voice, Email, Missed Call, and
WhatsApp Inbound) with prepaid billing.

[![CI](https://github.com/otp-id/otp-id-go/actions/workflows/ci.yml/badge.svg)](https://github.com/otp-id/otp-id-go/actions/workflows/ci.yml)

- Zero dependencies — standard library only.
- Faithful to the API: one method per endpoint, no hidden retries.
- Full API reference: https://docs.otp.id

## Install

```bash
go get github.com/otp-id/otp-id-go
```

Requires Go 1.15+.

## Quickstart

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	otpid "github.com/otp-id/otp-id-go"
)

func main() {
	client := otpid.NewClient(os.Getenv("OTPID_API_KEY"))
	ctx := context.Background()

	// 1. Send an OTP (code generated by OTP.ID, never returned to you).
	res, err := client.RequestOTP(ctx, otpid.OrderParams{
		Channel:     otpid.ChannelWhatsApp,
		Destination: "6281234567890",
		Brand:       "MyApp",      // shown in the OTP message; defaults to your merchant brand_name
		ExternalID:  "order-8821", // optional idempotency key
	})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("otp_id:", res.OtpID, "balance:", res.LastBalance)

	// 2. Later, verify what the user typed.
	v, err := client.VerifyOTP(ctx, res.OtpID, "482913")
	if err != nil {
		log.Fatal(err)
	}
	if v.Verified {
		fmt.Println("verified!")
	} else {
		fmt.Println("wrong code:", v.Reason) // "mismatch" — not an error
	}
}
```

## Error handling

Every non-success API response is an `*otpid.APIError`:

```go
res, err := client.RequestOTP(ctx, params)
if err != nil {
	var apiErr *otpid.APIError
	if errors.As(err, &apiErr) {
		switch apiErr.Code {
		case otpid.ErrCodeInsufficientBalance:
			// top up first
		case otpid.ErrCodeDuplicateExternalID:
			existing := apiErr.Details["existing_otp_id"] // recover the original transaction
			_ = existing
		case otpid.ErrCodeRateLimited:
			// slow down (20 requests per second per API key)
		}
		return
	}
	// network error, canceled context, or SDK-side validation (empty API key / empty otp_id)
}
```

A wrong code on `VerifyOTP` is **not** an error: the server answers HTTP 200
with `verified:false`, and the SDK returns `(*VerifyResult, nil)`. Expired,
locked, or already-used transactions do return an `*APIError`
(`OTP_EXPIRED`, `TOO_MANY_ATTEMPTS`, `ALREADY_USED`).

## Channels

| Constant | Value | Notes |
| --- | --- | --- |
| `ChannelWhatsApp` | `whatsapp` | `RequestOTP` + `SendOTP` |
| `ChannelSMS` | `sms` | `RequestOTP` + `SendOTP` |
| `ChannelVoice` | `voice` | `RequestOTP` only |
| `ChannelEmail` | `email` | `RequestOTP` + `SendOTP` |
| `ChannelMisscall` | `misscall` | use `RequestOTP` for misscall; user completes the caller's number |
| `ChannelWhatsAppInbound` | `whatsapp_inbound` | `RequestOTP` only; user messages OTP.ID |

### Bring your own code

```go
res, err := client.SendOTP(ctx, "482913", otpid.OrderParams{
	Channel:     otpid.ChannelSMS,
	Destination: "6281234567890",
})
```

### WhatsApp Inbound (user-initiated)

No code to type: show the user `res.Verification.WaLink` and let OTP.ID match
their incoming message. Never call `VerifyOTP` for these transactions —
detect completion via the `otp.verified` webhook or by polling `OTPStatus`.

```go
res, _ := client.RequestOTP(ctx, otpid.OrderParams{Channel: otpid.ChannelWhatsAppInbound})
fmt.Println("Ask the user to tap:", res.Verification.WaLink)
```

### Missed Call

The last digits of the calling number are the code. Show
`res.Verification.Prefix` and ask the user to complete the number, then pass
the completed digits to `VerifyOTP`.

## Webhook: `otp.verified`

OTP.ID signs every webhook with `HMAC-SHA256(secret, timestamp + "." + body)`.
`ParseVerifiedEvent` checks the signature (constant-time), rejects timestamps
outside ±5 minutes (replay protection), and decodes the payload:

```go
http.HandleFunc("/webhooks/otpid", func(w http.ResponseWriter, r *http.Request) {
	body, err := ioutil.ReadAll(http.MaxBytesReader(w, r.Body, 1<<20))
	if err != nil {
		w.WriteHeader(http.StatusBadRequest)
		return
	}
	ev, err := otpid.ParseVerifiedEvent(
		os.Getenv("OTPID_WEBHOOK_SECRET"),
		r.Header.Get("X-OTPID-Timestamp"),
		r.Header.Get("X-OTPID-Signature"),
		body,
	)
	if err != nil {
		w.WriteHeader(http.StatusUnauthorized)
		return
	}
	fmt.Println("verified:", ev.OtpID, "external_id:", ev.ExternalID)
	w.WriteHeader(http.StatusOK)
})
```

## Configuration

```go
client := otpid.NewClient(apiKey,
	otpid.WithBaseURL("https://api.otp.id"),          // default
	otpid.WithHTTPClient(&http.Client{Timeout: 10 * time.Second}),
)
```

The SDK never retries a request. If you add retries, only retry
`RequestOTP`/`SendOTP` calls that carry an `ExternalID` (the server replays
them idempotently) — retrying without one may deliver a second OTP.
